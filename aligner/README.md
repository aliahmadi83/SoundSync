# ابزار هم‌ترازی (Aligner) — راهنمای ساده برای ویندوز

با استفاده از دو اسکریپت آماده (`setup.sh` و `run.sh`)، کل کار به **۳ دستور**
خلاصه می‌شود: یکی برای نصب WSL، یکی برای نصب یک‌بارهٔ نرم‌افزارها، و یکی
برای پردازش سخنرانی‌ها (که هر وقت سخنرانی جدید داشتید، همان یک دستور را
دوباره می‌زنید).

نیازی به کپی‌کردن فایل بین ویندوز و WSL نیست — WSL مستقیم به پوشه‌های
ویندوز شما دسترسی دارد.

## گام ۱ (فقط یک‌بار در کل عمر ویندوزتان): نصب WSL

اگر قبلاً WSL/Ubuntu را نصب نکرده‌اید:
1. دکمه‌ی استارت را بزنید، بنویسید **PowerShell**، راست‌کلیک و **Run as
   Administrator**.
2. این را بزنید:
   ```
   wsl --install
   ```
3. کامپیوتر را ری‌استارت کنید. بعد از ری‌استارت یک پنجره‌ی Ubuntu باز
   می‌شود و یک‌بار از شما نام‌کاربری و رمز دلخواه می‌خواهد (هرچه خواستید
   وارد کنید).

اگر قبلاً WSL دارید، این گام را رد کنید.

## گام ۲ (فقط یک‌بار برای این پروژه): نصب

1. فایل zip دانلودی را در ویندوز Extract کنید، مثلاً در
   `C:\Users\YOUR_NAME\Downloads\LectureSync`.
2. پنجره‌ی **Ubuntu** را از منوی استارت باز کنید.
3. این دو خط را بزنید (به‌جای `YOUR_NAME` نام‌کاربری ویندوزتان را بگذارید
   — همانی که در مسیر `C:\Users\...` می‌بینید):
   ```
   cd /mnt/c/Users/YOUR_NAME/Downloads/LectureSync/aligner
   bash setup.sh
   ```
4. صبر کنید تا نصب تمام شود (چند دقیقه طول می‌کشد). یک‌بار رمز عبور
   اوبونتوتان را می‌خواهد.

## گام ۳ (هر بار که سخنرانی جدید دارید): پردازش

1. در **File Explorer ویندوز** (بدون نیاز به ترمینال)، فایل متن سخنرانی
   (مثلاً `speech1.docx`) و فایل صوت/ویدیوی هم‌نامش (مثلاً `speech1.mp4`)
   را در پوشه‌ی زیر بگذارید:
   ```
   Downloads\LectureSync\lectures
   ```
2. در همان پنجره‌ی Ubuntu (اگر بسته شد، دوباره باز کنید و `cd` گام ۲ را
   بزنید)، این یک خط را بزنید:
   ```
   bash run.sh
   ```
3. وقتی تمام شد، فایل‌های JSON را در پوشه‌ی زیر پیدا می‌کنید (مستقیم از
   File Explorer ویندوز، بدون نیاز به کپی‌کردن چیزی):
   ```
   Downloads\LectureSync\timings
   ```

همین. برای هر سخنرانی جدید فقط گام ۳ تکرار می‌شود.

## اگر خطا دیدید
متن دقیق پیام خطا را کپی کنید و بفرستید. رایج‌ترین خطاها معمولاً مربوط به
نصب‌نشدن درست `aeneas` است که با یک اصلاح کوچک در `requirements.txt` یا
نصب یک بسته‌ی سیستمی اضافه حل می‌شود.

## نکات فنی (اختیاری، برای کنجکاوها)
- `align.py` خودش نه ASR بلکه Forced Alignment انجام می‌دهد: متن از قبل
  مشخص است، فقط زمان دقیق هر جمله در فایل صوتی پیدا می‌شود.
- `run.sh` را می‌توانید با آرگومان هم صدا بزنید:
  `bash run.sh مسیر_ورودی مسیر_خروجی زبان` — پیش‌فرض‌ها `../lectures`،
  `../timings` و `fas` (فارسی) هستند.
- اگر کیفیت هم‌ترازی فارسی راضی‌کننده نبود، جایگزین رایگان دیگری به اسم
  WhisperX هم هست؛ اگر لازم شد بگویید تا این اسکریپت را با آن هم پیاده‌سازی
  کنم.
