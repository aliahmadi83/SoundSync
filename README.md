# LectureSync — نمایش هم‌زمان متن و صوت سخنرانی

## معماری

```
[متن سخنرانی + فایل صوت/ویدیو]
            │
            ▼
   aligner/align.py   (پایتون، آفلاین، اجرای یک‌باره برای هر سخنرانی)
            │  aeneas: هم‌ترازی اجباری متن با صوت (نه تشخیص گفتار)
            ▼
     فایل JSON زمان‌بندی  (start/end هر جمله)
            │
            ▼
BlazorApp/LectureSync.Client   (Blazor WebAssembly، کاملاً کلاینتی)
   - فایل Word/txt سخنرانی را در مرورگر با mammoth.js می‌خواند
   - فایل صوت/ویدیو را پخش می‌کند
   - فایل JSON زمان‌بندی را می‌خواند
   - حین پخش، جمله‌ی جاری را هایلایت می‌کند
   - با کلیک روی هر جمله، پخش را به ابتدای همان جمله می‌برد و متوقف می‌کند
```

هیچ سروری در زمان اجرای برنامه‌ی Blazor لازم نیست؛ پایتون فقط یک‌بار و
جداگانه، برای ساختن فایل JSON هر سخنرانی اجرا می‌شود (به همین دلیل «دسته‌ای»
طراحی شده: می‌توانید چند سخنرانی را با یک دستور پردازش کنید).

## گام‌ها برای هر سخنرانی جدید

1. متن سخنرانی را به‌صورت `.docx` یا `.txt` و فایل صوت/ویدیوی متناظر را
   آماده کنید (هر دو با نام یکسان، فقط پسوند متفاوت).
2. طبق `aligner/README.md`، اسکریپت را اجرا کنید تا فایل JSON زمان‌بندی
   ساخته شود.
3. برنامه‌ی Blazor را اجرا کنید (پایین را ببینید) و هر سه فایل (متن، رسانه،
   JSON) را در آن بارگذاری کنید.

## اجرای برنامه‌ی Blazor

نیاز به .NET SDK 8 دارید (رایگان، از dotnet.microsoft.com/download).

```bash
cd BlazorApp/LectureSync.Client
dotnet restore
dotnet run
```

سپس آدرسی که در ترمینال چاپ می‌شود (معمولاً something like
`http://localhost:5000`) را در مرورگر باز کنید.

برای انتشار به‌صورت فایل‌های استاتیک (بدون نیاز به dotnet در سرور نهایی):
```bash
dotnet publish -c Release -o ./publish
```
خروجی پوشه‌ی `publish/wwwroot` را می‌توانید روی هر وب‌سرور ساده (یا حتی
به‌صورت فایل local، با کمی محدودیت CORS مرورگر) میزبانی کنید.
